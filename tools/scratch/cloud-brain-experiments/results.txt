What the results change:

- **The runtime's scheduler must be replaced in a Worker.** \`runtime.js\` line 7 picks \`requestAnimationFrame\`, else \`setImmediate\`, else \`setTimeout\`. \`module.value()\` deletes its temporary variable in a \`finally\` (\`module.js\` line 65), which schedules a compute on a timer after the response has been sent. Workers drop a request's timers when it ends, so \`runtime._computing\` stays pending and every later request waits on it. Defining \`globalThis.requestAnimationFrame\` as a microtask before the runtime loads fixed it. This belongs in \`host.js\`.
- **"Computed once per isolate" was wrong as written.** \`module.value(name)\` observes the cell for the length of the call and then releases it, so the cell and everything above it is recomputed on the next call. A handler cell keeps its value only if the host defines it with an observer. The host should observe \`fetch\`, \`jobs\` and \`socket\` at boot.
- **No change to \`robocoop-5-core\` is needed to run a turn or to resume one**, on the evidence of a scripted model. A turn cannot be paused between model calls: \`send()\` is one loop. Resuming is a new \`send()\` on a restored transcript, which adds a user message.
- **QuickJS is feasible for on-demand self-modification.** Two shapes both ran: the whole runtime inside the interpreter, or the host's runtime with interpreted cell bodies. The second keeps one runtime and lets native and interpreted cells depend on each other. Its costs are measured above: 12 to 18 times slower on a tight loop, 232 KB gzipped per upload, and an interpreted cell sees none of the platform (\`URL\`, \`fetch\`, \`crypto\`) unless the host hands each one in.
- **Dynamic Workers are feasible for the same job** and give the new code the full platform at native speed, in a separate isolate.

Not settled by these runs: whether any of it behaves the same on Cloudflare's edge; QuickJS under the CPU limit with a real cell; memory when a context lives across requests (a context with a pending host promise failed QuickJS's leak assertion on dispose, \`list_empty(&rt->gc_obj_list)\`, in my harness).
