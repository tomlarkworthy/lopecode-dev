## What changed

`!o.isCompactSummary`. The comment at the head of the file says so. A row with an `origin` is judged
by its `origin` as before. No compaction row read has one:
`grep -rh '"isCompactSummary":true' ~/.claude*/projects --include='*.jsonl'`, each line parsed, gives
330 `user` rows with the flag and 0 of them with an `origin`.

`tests/tools/agent-usage.test.ts`, one test added, "a compaction's summary row is not a prompt": a
transcript of a prompt, a coordinator's message, the summary row and two more requests, where
`--last-run` and `--run 2` are the three requests after the coordinator's message and `--run 3` is
none; and one of a prompt and a summary row, where `--last-run` is the whole file and `--run 2` is none.
Before the change it failed (`requests` 2 where 3 was expected), 8 pass and 1 fail.
